# 📱 Landing App

Full-stack mobile app built with React Native (Expo), Node.js, and PostgreSQL.

---

## 🚀 Features

- Contact form (Name, Email, Message)
- Send data to backend API
- Store messages in PostgreSQL

---

## 🧠 Tech Stack

- React Native (Expo)
- Node.js + Express
- PostgreSQL

---

## 📡 API

### POST /contact

Send message to server and save it in database.

---

## 🗄️ Database

Table: contacts

- id
- name
- email
- message
- created_at

---

## ▶️ Run Project

### Frontend

```bash
npx expo starttest
```
